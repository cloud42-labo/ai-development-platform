# Templates

Reusable ADP templates belong here when they are intended to be copied or instantiated across products, Epics, Stories, controls, reviews, or operating documents.

Template content should be generic, public-safe, and independent of live Notion status.

## Index

| [`inception-deck.md`](inception-deck.md) | `docs/inception-deck.md` — Inception Deck, per the same standard |

| [`epic-brief.md`](epic-brief.md) | The lightweight Epic Brief inside an Epic's Notion page, per the same standard |
